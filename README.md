
# Notes App

A simple and responsive notes application built with React, Vite, and CSS. The app allows users to create, view, and delete notes, with notes stored in the browser's Local Storage.

## 🚀 Features

- Create and save notes
- View saved notes
- Delete notes
- Persistent data using Local Storage
- Responsive user interface
- Reusable React components
- Home and About pages

## 🛠️ Tech Stack

- Frontend: React.js
- Language: JavaScript (JSX)
- Styling: CSS
- Build Tool: Vite
- Storage: Browser Local Storage
- Linting: ESLint

## ⚙️ Installation & Setup

1. Clone the repository

2. Navigate to the project directory

cd notes-app-styled

3. Install dependencies

npm install

4. Start the development server

npm run dev

Open the local URL displayed in the terminal to view the application.

## 💾 Data Storage

The application uses Browser Local Storage to store notes. This allows saved notes to remain available even after refreshing the page.

## 📌 Project Status

This project was built as a React learning and portfolio project to practice component-based development, state management, CSS styling, and browser Local Storage.
