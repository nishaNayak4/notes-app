# Notes App

A simple and responsive notes application built with React, Vite, and CSS.

## 🚀 Features

- Create, view, and organize personal notes
- Responsive UI with styled components
- Fast client-side rendering powered by Vite

## 🛠️ Tech Stack

- **Frontend:** React (JSX)
- **Styling:** CSS
- **Build Tool:** Vite
- **Linting:** ESLint
